---

## 1コマ目：課題 — 生成モデルは便利だけど現場で使うと壊れる

**【背景】研究室/制作現場**

| キャラ | 吹き出し |
|---|---|
| 監督（左） | 「AI で背景や素材を量産したい。でもキャラの顔が崩れたり、構図がおかしなことになる…」 |
| 技術者（右） | 「しかも全員同じ『平均的なキレイ』しか出せない。私たちの絵柄が消える。」 |
| ナレーション | 生成モデルは便利だが、構成崩壊・同一化・個性喪失が課題。 |

**使用論文**: P22 Aesthetic Alignment Risks Assimilation

---

## 2コマ目：提案 — Director + VLM critic でループを回す

**【背景】システム図のような空間**

| キャラ | 吹き出し |
|---|---|
| 技術者 | 「AniME や Iterative Refinement のやり方を借りよう。Director agent が MCP ツールを選んで、VLM が生成結果を採点。」 |
| 監督 | 「つまり、生成→評価→修正を自動で回す？」 |
| 技術者 | 「そのとおり。text-image 類似度、identity、narrative 評価で品質を測る。」 |
| ナレーション | 生成物をループに入れ、自律的に改善する枠組み。 |

**使用論文**: P01 AniME, P05 Iterative Refinement

---

## 3コマ目：罠 — 無限ループは崩壊し、既存 RM は敵になる

**【背景】警告サインが点滅する画面**

| キャラ | 吹き出し |
|---|---|
| 警報システム | 「警告：5 回自己再学習で顔が崩壊。3% synthetic 混入で劣化開始。」 |
| 技術者 | 「Neural Resonance の指摘だ。ループを無制限に回すとモデル collapse する。」 |
| 監督 | 「しかも既存の reward model は私たちの絵を低評価にするのか…」 |
| 技術者 | 「PAMELA で個人別 RM を作るしかない。Chat2SVG みたいに 2-stage で破綻も防ぐ。」 |
| ナレーション | ループにはガードが必要。既存評価軸では個性が潰される。 |

**使用論文**: P08 Neural Resonance, P22 Aesthetic Alignment, P19 PAMELA, P30 Chat2SVG

---

## 4コマ目：解決 — 少データで育て、1本の LoRA に統合する

**【背景】完成したシステムの全景**

| キャラ | 吹き出し |
|---|---|
| 技術者 | 「IC-LoRA で 20〜100 枚からスタイルを学習。SLAO で複数 LoRA を 1 本に統合し続ける。」 |
| 監督 | 「つまり、履歴が失われず、個人の好みも蓄積される？」 |
| 技術者 | 「その上で Director + VLM critic が反復改善。Chat2SVG 式の 2-stage 生成で破綻も防ぐ。」 |
| 監督 | 「これなら、私たちの絵柄を AI に引き継げる。」 |
| ナレーション | 少データ適応、継続統合、個人別評価、破綻防止の 4 接合が新規性。 |

**使用論文**: P11 IC-LoRA, P16 SLAO, P01, P05, P30
