## Boundary

- Project — ひとつの問いを検証する単位
- Research — 実験結果・調査・文献
- Implementation — 実際に動かすコード
- Ontology — 複数プロジェクトから抽象化する共通モデル

PROJECT → QUESTION → EXPERIMENT / CASE → OBSERVATION → ONTOLOGY
