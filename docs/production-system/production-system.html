PRODUCTION ARCHITECTURE / ANIMATED FEATURE FILM

AIアニメ映画制作システム

生成をお呪いから科学へ、錬金術から工場へ。

Referenceが制作対象を定義し、Generationが候補を作り、Eval/JEVが根拠をもって判断し、Production System（TPS/Gate）が完成までの流れを管理する。

4つの独立レイヤー

1. Reference

問い：何を作るか？

物語・脚本・キャラクター・世界観・絵コンテなどの正本と参照コンテクスト。

  • TEXT：アイデア、脚本、コード
  • YAML：設定・構成
  • PNG：ラフ、写真、生成画像
  • HTML：キャラクターシート
  • SVG：絵コンテ、4コマ
  • RAG：チャンク検索インデックス

構造化データを正本とし、RAGは検索用として扱う。

2. Generation

問い：どう候補を作るか？

モデル、プロンプト、パラメータ、参照版、seed（利用可能な場合）、実行時刻、費用、生成物のURIを記録する。

候補と採用済み素材を分け、再現・比較・再実行を可能にする。

3. Eval / JEV

問い：何を合格とするか？

命題、証拠、評価基準、スコア、確信度を紐付けて判断する。

判定：PASS / REVISE / REJECT / NEEDS_HUMAN_REVIEW

設定一貫性、構図、破綻、意図、ショット連続性、タイミング、音声を検査する。

4. Production System / TPS-Gate

問い：どう完成まで流すか？

  • Gate A：仕様・参照資料の準備
  • Gate B：素材検査
  • Gate C：ショット検査
  • Gate D：納品検査

合格素材だけを次工程へ送り、待ち・手戻り・重複生成・廃棄を減らす。

制作フロー

企画・世界観 → 脚本 → キャラクター／美術設定 → 絵コンテ／アニマティック → ショット生成 → Eval/JEV → 編集／合成 → 音響／音楽 → 最終QC／納品

不合格時：失敗原因に応じて該当工程へ戻す。すべてを最初から再生成するのではなく、原因と修正先を記録する。

評価指標（KPI）

  • First-pass yield：初回評価で合格した素材の割合
  • Final yield：最終的に採用された素材の割合
  • Rework rate：修正・再作業が発生した素材の割合
  • Cost per accepted shot：生成費＋修正工数を合格ショット数で割ったコスト
  • Canon consistency rate：正本設定との一貫性
