# EXP-CTX-001 — 全要素コンテキスト反復生成

## 対象RQ

- **RQ0**（主RQ）: 評価結果を次の生成入力へ還元するループがプロンプト単発生成を上回るか
- **RQ1**: 多軸評価の分解が効果的か
- **RQ2**: 評価差分を生成条件へ変換できるか

## 用語定義

| 用語 | 意味 |
|---|---|
| **全要素コンテキスト** | 前回の (1)生成プロンプト (2)生成画像（パス） (3)パラメータ (4)オントロジ記述 (5)細かな採点 を、次の生成リクエストに含める入力形式 |
| **細かな採点** | quality, style, semantic, preference に加え、composition, color, line, mood の4サブ軸を 1〜5 で採点 |
| **オントロジ記述** | Change Ontology の概念で、生成対象の STATE / DIFFERENCE / TRANSFORMATION をタグ付けした記述 |

## 仮説

> **H1** 前回の生成結果（プロンプト・画像・パラメータ）と細かな採点・オントロジ記述を、次回生成のテキスト入力コンテキストに含めることで、目標への到達に必要な反復回数が、プロンプト単発群（A）と比較して有意に減少する。

> **H2** 採点のサブ軸（composition, color, line, mood）を明示してフィードバックすることで、5段階総合スコアのみの群（C）よりも収束が速くなる。

> **H3** オントロジ記述（STATE, TRANSFORMATION タグ）を付加することで、VLM critic や人間評価者の判断基準が安定し、評価の分散が減少する。

## 統制群

| 群 | 入力に含めるコンテキスト | 評価フィードバック | 目的人口 |
|---|---|---|---|
| **A** 単発 | なし（固定プロンプト） | なし | ベースライン |
| **B** プロンプト継承 | 前回プロンプトのみ | なし | 継承だけの効果 |
| **C** プロンプト＋総合採点 | 前回プロンプト＋総合スコア（1軸） | 総合スコアのみ | 単純フィードバック |
| **D** 全要素コンテキスト | 前回プロンプト＋画像パス＋パラメータ＋オントロジ＋**細かな採点** | サブ軸スコアを自然言語化して追記 | **本提案** |

## 実験方法

### 1. タスクの設定

同一の目標提示文（目標オントロジ＋目標画像イメージのテキスト記述）を、4群に与える。

目標例：
```
目標: 夕暮れの廃工場に立つ少女。構図は横長、左寄り。色温度は低く、橙が強い。
線は力強く、ムードは寂寥感。
オントロジ: STATE:廃工場+少女, TRANSFORMATION:日→夕暮れ, RELATION:左寄り構図
目標スコア: quality>=4, color>=4, mood>=4
```

### 2. 反復ルール

- 各群、同一の初期プロンプトで開始
- 1反復 = 生成 → 評価 → コンテキスト更新 → 次の生成
- 人間評価者が各反復後に採点
- 採点基準を満たすか、最大10反復で打ち切り

### 3. 採点シート（細かな採点）

```
[反復 {t} / 群 {X}]
- quality（総合品質）: 1 2 3 4 5
- composition（構図）: 1 2 3 4 5
- color（色調）: 1 2 3 4 5
- line（線質）: 1 2 3 4 5
- mood（ムード/雰囲気）: 1 2 3 4 5
- semantic（意図一致）: 1 2 3 4 5
- preference（好み）: 1 2 3 4 5
```

### 4. コンテキストの作り方（D群のみ）

前回の `run_context.json` を読み込み、以下を追記して次回へ渡す。

```json
{
  "previous_runs": [
    {
      "run_index": 1,
      "prompt": "a girl standing in a factory...",
      "negative_prompt": "...",
      "parameters": { "cfg": 7.0, "steps": 20, "seed": 42, "width": 512, "height": 512 },
      "ontology": ["STATE:廃工場+少女", "TRANSFORMATION:日中→夕暮れ"],
      "image_path": "exp-ctx-001/D/run-001.png",
      "evaluation": {
        "quality": 3, "composition": 2, "color": 4, "line": 3, "mood": 2,
        "semantic": 3, "preference": 3
      },
      "feedback_text": "構図が中央寄りすぎ。ムードが明るすぎる。色は合格。線をもっと力強く。"
    }
  ]
}
```

次回の生成プロンプトは、上記を自然言語に展開して冒頭に付加する：

```
[履歴]
前回1: 廃工場に立つ少女。構図中央寄り（composition=2）。色温度低め（color=4）。
線質普通（line=3）。ムード明るめ（mood=2）。
→ 改善指示: 構図を左寄りに。ムードを寂寥感へ。線を力強く。

[今回の要求]
夕暮れの廃工場に立つ少女。構図は横長、左寄り。色温度は低く、橙が強い。
線は力強く、ムードは寂寥感。
```

### 5. 中止基準

| 条件 | 動作 |
|---|---|
| 目標スコア全軸達成 | 成功、反復終了 |
| 反復10回到達 | 打ち切り、中間最良を記録 |
| 連続3回で同一スコア | 停滞判定、パラメータ摂動を試行 |
| スコアが単調減少3回 | 崩壊疑い、該当runを破棄記録 |


## 出力指標

1. **到達反復回数**（目標達成まで）
2. **最終スコア**（全軸平均）
3. **スコア上昇率**（(最終−初回) / 反復回数）
4. **評価者間一致率**（2名以上で採点した場合の Cohen's κ）

## 判定基準

- **成功**: D群の平均到達反復回数が A群の 50% 未満
- **部分的成功**: DがCを上回るがAの50%未満には達しない → H1の部分成立
- **失敗**: DとCの差が有意でない → 細かな採点の付加価値なし
- **沈黙**: 全群で3回以上で目標に到達しない → 初期プロンプトまたは目標設定の問題
