# 研究質問の宣言

対象は **画像生成**。プロンプト工学が研究対象ではない。

> **研究対象を 1 文で**
> 　　 「生成物・評価・オントロジ・運用者の好」を**すべて文脈として与えて**、
> 　　 **同じ重みのローカルモデルを ICL と LoRA で継続的に育てる**構成が、
> 　　 制作現場でプロンプト改良や単発 fine-tuning を**上回るか**。

# 主 RQ

> **RQ0**
> オントロジ・生成物履歴・自己評価・ 好みのパラメータを統合した文脈を推論時に与え、
> 加えて反復評価の履歴で単一 LoRA を継続更新する構成は、
> (a) 指示のみのプロンプト、(b) 文脈のみ（重み無改変）、(c) 単発 fine-tuning
> のいずれ也别，对照実験で制作意图の再現率と作业負担をTemporal改善できるか。

**改善の2軸**

| 軸 | 指標 | 測り方 |
|---|---|---|
| 再現 | 意図一致率（生産者blink評定 5段階） | 盲検(pairwise) |
| 負担 | 到達までの反復回数・時間 | ログ自動採取 |

# 比較 설계（統制群）

| 群 | 文脈 | LoRA | 何 decades |
|---|---|---|---|
| **A** | 指示のみ | なし | 現UES. ベースライン |
| **B** | 4要素 | なし | ICL の効果（P09 P10 P11） |
| **C** | 指示のみ | 単発 | fine-tuning の効果 |
| **D** | 4要素 | 継続更新 | **本提案** |
| **E** | 4要素 | 継続更新 + collapse guard | **D の破綻対策** |

主要比較は **B vs D**（文脈に重み更新を足す意味）と **D vs E**（破綻の乗り切り方）。

# 反証条件（これが満たらないなら RQ は否定される）

| RQ | 否定される条件 |
|---|---|
| RQ0 | D が B を上回らない、または負担が-cnogo悪化する |
| RQ1 | 要素を増やしても向上は頭打ち／*Noise* で有意差なし |
| RQ2 | 継続更新で過去概念の再現率が単調に落ちる（→ D を主张できない） |
| RQ3 | ループを 3 回回すだけで破綻し、guard が構成できない（→ 実運用不可） |
| RQ4 | 個人別 RM と汎用 RM の順位相関がほぼ 1.0（→ RQ4 の主張を捨てる） |
| RQ5 | Blender / Houdini / SVG に落とすと技術的に破綻（→ 範囲を狭める） |

**特に RQ0 は「D ≤ B なら本手法は成立しない」。この 1 点が卒制の成否を分ける。**
