# 統計・数学（NDim タスク必須のみ）

> 巨人の肩の広大なリストではなく、**NDim（自然言語→寸法→bpy）の業務を完了させるのに必要な**統計と数学だけ。

## 統計学

### 1. 単位推測の不確実性管理（既に実装中）
- `Param.is_ambiguous_unit` — 単位未指定時は「1.0 未満＝ミリ、1.0 以上＝メートル」を推定。1000 倍ずれのリスク源。
- 必要な概念：**点推定 vs 区間推定**、リスクの定量化。
- 実測指標: `ambiguous_rate = 単位なし入力 / 全入力`。これが高ければ入力規約を厳格化（単位必須）。

### 2. 寸法抽出精度の評価（Phase 5 評価の核）
- 必要な概念：**Precision / Recall / F1、平均絶対誤差 (MAE)**
- 固定フィクスチャ 30〜50 件で測定:
  - 精度 = 抽出された寸法が正しい割合
  - 再現率 = 存在する寸法が全て抽出された割合
  - MAE = |抽出値 - 正解| の平均（メートル単位、例 0.002 m）
- 統計的推論: **95% 信頼区間**（正規近似）で精度のばらつきを報告
  - `p ± 1.96·√(p(1-p)/n)` — 検定は不要（単一システム評価）

### 3. 生成物の尺度検証（許容誤差以内の割合）
- 必要な概念：**公差**（許容誤差）、一致率
- 検証: 生成オブジェクトの `scale` が `Param` と `±1 mm` 以内か
  - 一致率 = (許容以内 / 総数) → 目標 > 99%
- **1000 倍ミストラップ検出**: `scale` の外れ値を z-score で検知（例: |z| > 3 のオブジェクトを警告リストへ）

### 4. 相対指示の累積誤差評価
- 必要な概念：**累積誤差**、線形ドリフト
- 検証: n 回適用後の誤差 = n × 1 回の誤差（線形なら問題なし）。`build_relative` の非冪等性を manifest の `relative_count` で追跡。

## 数学

### 1. 単位換算（線形写像）
- 単位換算は **×変換数** の線形写像 → 可逆、誤差は比例（相対誤差不変）。
- 1000 倍ミストラップの可視化: 桁ズレは対数尺度で確認（`log10(value)` 分布）。

### 2. COMPLEX 配置（等差数列）
- `x_i = i × (v + gap)` — 等差数列による配置
- 総延長の閉形式: `L = (n-1)×(v + gap)`（検証用）
- 総体積積算（manifest 出力時）: 形状ごとの厳密式（後述）

### 3. 幾何体の体積・面積（報告統計）
- cube: `v³` （size=1 に scale=v）
- cylinder: `π·(v/2)²·v = πv³/4` （radius=v/2, depth=v に scale=v）
- plane: `v²`（面積）
- 総体積 = Σ（物体ごとの体積）— 報告用に集計

### 4. ベクトル計算（mathutils がないため numpy 代替）
- `mathutils.Vector/Matrix/Quaternion` はこの環境に**不存在** → `numpy` で対応
- 回転は `rotation_euler` の tuple 操作のみ（`r + delta` で可能）
- Matrix 計算が必要なら `numpy.array` で自作（例: 配置行列）
