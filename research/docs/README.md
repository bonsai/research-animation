# research — 生成画像の評価とフィードバック

本ディレクトリは **生成されたイメージを対象とした評価・フィードバックの研究** を蓄積する。

`research-animation` の上位テーマ（アニメ映画生成の理論構築）の中で、画像出力そのものを評価し、その結果を次の生成条件へ還元するループ構造を検証する。

## テーマ宣言

> **生成画像の品質・意図一致度・個人嗜好を、自動評価と人間評価の双方で測定し、その差分を次の生成入力（プロンプト・パラメータ・重み）へのフィードバックとして使うことで、反復的な画像改善がプロンプト工学を超えて成立するか。**

上位プロジェクトの `Change Ontology` から特に以下の要素を対象とする：

- **STATE**: 生成された画像（静的・フレーム）
- **DIFFERENCE**: 評価スコアの変動・差分
- **EVALUATION**: VLM critic / 自動指標 / 人間評価
- **FEEDBACK**: 評価→入力変換（反射）
- **TRANSFORMATION**: プロンプト・LoRA・パラメータの改変
- **LOOP**: 生成→評価→フィードバック→再生成の循環

## 境界

本ディレクトリでは扱わないもの：
- 動画生成モデルのファインチューニングそのもの
- 3DCG / CAD / BIM の実装詳細
- 大規模な事前学習
- 最新レンダリング技術の性能競争

これらは `anima` / `dots` / `bonsai` 各ケース側で管理する。

## 規約

- 理論を先にし、実装は検証道具として位置づける
- 実験ごとにマニフェスト（JSON）を残し、再現性を持たせる
- `Observation ≠ Interpretation ≠ Evidence`
